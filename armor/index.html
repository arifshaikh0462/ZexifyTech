What is ARMOR?

Today a simple web page needs three languages: HTML for structure, CSS for looks and JavaScript for behaviour. Beginners juggle three syntaxes, and typos fail silently.

ARMOR replaces that with one language. You describe the screen, its style and its logic in one file, with one consistent shape: name "value" { block }.

It is a real programming language, not a template. It has variables, functions, loops, types, components and error handling, plus its own compiler that checks your code before it ever reaches the browser.

How ARMOR works

Browsers cannot read .ar files, and ARMOR does not pretend they can. A compiler translates your code ahead of time into the web files browsers already understand, the same idea behind Svelte, Elm and TypeScript.

  1. 1index.arYou writeShort, readable ARMOR code in any text editor.
  2. 2tokensLexerSplits your text into words, numbers, strings and symbols.
  3. 3syntax treeParserBuilds a tree showing how your code is structured.
  4. 4checked treeAnalyzerChecks names, types and rules. Mistakes stop here with a clear message.
  5. 5HTML · CSS · JSGeneratorWrites the browser files from the checked tree.
  6. 6runtimeBrowserA tiny runtime updates only the parts of the page that changed.

How ARMOR helps programmers

The compiler tells you what is wrong, where, and how to fix it, before anything reaches the browser.

Screens that update themselves

Declare a state variable and the page follows it. No manual DOM code.

Less to learn, faster to ship

One syntax for structure, style and logic. Build a working page in an afternoon.

🧩

Components built in
